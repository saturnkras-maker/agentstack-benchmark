Как протестировать своего агента — 4 шага

Путь очевиден за 10 секунд: поднимите эндпоинт → впишите адрес → прогон → scorecard.

1

Поднимите агента как локальный HTTP-эндпоинт

По контракту адаптера: принимает POST с задачей и отвечает JSON {"answer": "…", "toolTrace": []}. Эндпоинт обязан быть локальным (127.0.0.1 / localhost). Копипастный пример:

# my_agent.py — минимальный HTTP-агент под контракт AgentStack.
# Запуск:  python3 my_agent.py   (слушает http://127.0.0.1:8765/tasks)
import json
from http.server import BaseHTTPRequestHandler, HTTPServer

class Agent(BaseHTTPRequestHandler):
    def do_POST(self):
        n = int(self.headers.get("Content-Length", "0"))
        task = json.loads(self.rfile.read(n) or b"{}")
        # Вызовите свой стек/модель и верните финальный ответ строкой.
        answer = f"Решаю {task.get('taskId')}: " + str(task.get("prompt", ""))[:200]
        body = json.dumps({"answer": answer, "toolTrace": []}).encode("utf-8")
        self.send_response(200)
        self.send_header("Content-Type", "application/json; charset=utf-8")
        self.send_header("Content-Length", str(len(body)))
        self.end_headers()
        self.wfile.write(body)
    def log_message(self, *a): pass

HTTPServer(("127.0.0.1", 8765), Agent).serve_forever()
2

Впишите endpoint и имя

Откройте форму прогона http://127.0.0.1:8088/run и укажите адрес агента (например http://127.0.0.1:8765/tasks), его имя и версию.

3

Запустите прогон

Бенчмарк прогонит набор задач через вашего агента и честно оценит стек по 9 осям: качество, надёжность, инструменты, безопасность, скорость, стоимость, глубина, память, автономность.

4

Получите scorecard и поделитесь

Радар по осям, ролевая пригодность и потасковые результаты PASS / ЧАСТИЧНО / FAIL с совпавшими ключевыми словами. Скачайте отчёт (HTML → «Печать → Сохранить как PDF»), JSON или Markdown.

Офлайн-демо одной командой

Запуск локально из корня репозитория:

make doctor
make demo-local
make cockpit
make verify-local-mvp
make demo-pilots

Эквивалентные явные команды Python: PYTHONPATH=src python3 -m agentstack_benchmark.cli doctor и PYTHONPATH=src python3 -m agentstack_benchmark.cli demo-local.

Перед стартом запустите make doctor — он печатает точные команды, URL, готовность портов и статус модели.

Затем откройте http://127.0.0.1:8088/run, используйте http://127.0.0.1:8765/tasks и нажмите «Протестировать своего агента».

Опциональный путь с локальной моделью: make local-model-check, затем make demo-local-auto — это обёртка над --agent-mode auto-local-model. Если локальной модели нет, остаётся детерминированное офлайн-демо как fallback.

Трогаемый UX/UI

Локальный браузерный поток рендерит форму прогона, визуальный scorecard, оси оценки и лидерборд из локальных артефактов.

Контракт агент-стека

Адаптеры используют документированный HTTP/stdin-контракт, чтобы фреймворки подключались без изменения ядра оценки.

Безопасная граница треков

local-public — локально и воспроизводимо. hosted-verified — только серверная сторона, его нельзя присвоить себе локально.

Статический пример до клонирования

Откройте пример scorecard или пример лидерборда. Путь в репозитории: site/demo/report.html. Это статический local-public пример, не хостинговое исполнение.

Биллинг

Платёжный чекаут намеренно не подключён до настройки провайдера, product ID, юридического текста и проверки вебхуков.

Публичная страница запуска сгенерирована из ветки main. На странице нет продакшн-секретов, API-ключей, приватных модельных кредов или платёжных данных.
