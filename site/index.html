One-command offline demo

Run locally from the repository root:

make doctor
make demo-local
make cockpit

Equivalent explicit Python commands: PYTHONPATH=src python3 -m agentstack_benchmark.cli doctor and PYTHONPATH=src python3 -m agentstack_benchmark.cli demo-local.

Before starting, run make doctor to print exact local commands, URLs, port readiness, and model status.

Then open http://127.0.0.1:8088/run, use http://127.0.0.1:8765/tasks, and click Run benchmark.

Optional local model path: run make local-model-check, then make demo-local-auto — it wraps --agent-mode auto-local-model. If no loopback model is available, the deterministic offline demo remains the fallback.

Touchable UX/UI

Local browser flow renders a run form, visual report, dimension scorecards, and leaderboard from local artifacts.

Agent-stack contract

Adapters use a documented HTTP/stdin contract so frameworks can plug in without changing the scoring core.

Safe track boundary

local-public runs are local and reproducible. hosted-verified is server-side only and cannot be self-assigned locally.
