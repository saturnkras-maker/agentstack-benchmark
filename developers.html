Для разработчиков: полный авто-прогон

Публичная проверка на главной — это экспресс-срез по тексту ответов (4 оси). Полная картина агента снимается автоматическим прогоном по контракту — здесь живёт вся техническая часть.

Экспресс (сайт) vs полный прогон (cockpit)

Экспресс честно меряет только то, что видно в одном текстовом ответе. Память, реальный tool-use, автономность, восстановление после ошибки и стоимость на объёме одним ответом не измерить — для них нужен живой прогон агента в песочнице.

Адаптер-контракт

Агент подключается через документированный HTTP/stdin-контракт (adapter/endpoint), поэтому любой фреймворк встраивается без изменения ядра скоринга. Прогон детерминирован: канонический порядок полей, хэши артефактов, метаданные дисперсии/доверительного интервала, редакция секрето-подобных строк.

$ agentstack run --pack richer_v1 --adapter http://localhost:8080/agent \
    --track local-public --out report.json
  • local-public — локальный воспроизводимый прогон (то, что на сайте по духу).
  • hosted-verified — серверный прогон со скрытыми задачами, его нельзя присвоить себе локально (анти-чит).

Прозрачность скоринга

И экспресс, и полный прогон используют детерминированные чек-листы (must-have ключи/структуры/паттерны → баллы по осям). LLM-as-judge в ядро скоринга не входит. Результат экспресс-проверки на сайте считается полностью на стороне браузера — задание и ответы пользователя не покидают устройство.

Полный прогон, контракт адаптеров и cockpit — в репозитории проекта. Экспресс-сайт намеренно не содержит сетевых вызовов с заданием/ответами.
